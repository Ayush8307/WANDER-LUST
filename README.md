# WANDER-LUST 

WanderLust is a full-stack vacation rental web application inspired by Airbnb. It allows users to explore, list, and manage rental properties while providing a seamless booking experience. The platform offers user authentication, property management, image uploads, reviews, and responsive design for an enhanced user experience.

🚀 Features
🔐 User Authentication & Authorization
🏠 Create, Edit, and Delete Property Listings
📸 Property Image Uploads
⭐ Ratings and Reviews System
🔍 Search and Browse Listings
📱 Fully Responsive Design
🗺️ Interactive Property Details
👤 User Profile Management
⚡ Fast and Dynamic User Interface
